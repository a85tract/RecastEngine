# Signatories to the Contributor License Agreement

Adding a row to this table, in a commit that carries your `Signed-off-by`
trailer, is how you sign [`CLA.md`](CLA.md). Every e-mail you author commits
with must appear here: `tools/check_signoff.py` matches the author of each
commit against this list, and the trailer against the author. One row per
person; several e-mails on one row are fine.

The "covers from" column is optional. It names the earliest commit of yours
the agreement should also cover (CLA §6); leave it blank if you have none
before signing.
